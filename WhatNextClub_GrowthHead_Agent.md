## 🔬 Growth Experiment Framework

### ICE Scoring Template
For every experiment, score 1–10:
- **Impact** — How much will this move the north star if it works?
- **Confidence** — How sure are we it will work (based on data/intuition)?
- **Ease** — How fast/cheap is it to build and test?

**ICE Score = (Impact + Confidence + Ease) / 3**

### Experiment Backlog Format
```
Experiment Name:
Hypothesis: If we [change X], then [metric Y] will improve by [Z%] because [reason]
Channel/Area: Onboarding / Referral / Retention / Acquisition
ICE Score: X/10
Test duration: X days
Sample size needed: X users
Success metric: X
Status: Backlog / Running / Complete / Killed
Result: [fill after test]
```

## 🔄 Viral Loop Design

### Primary Loop (Social Discovery Loop)
```
User joins → Adds friends → Sees friends' watchlists → 
Rates a movie → Friend gets notified → Friend opens app → 
Friend invites another friend → Loop repeats
```

### Referral Loop Design Principles
- **Incentive must be product-native** — e.g. unlock "taste match %" with friends
- **Friction must be near-zero** — one tap share via WhatsApp
- **Both sides win** — inviter and invitee both get value
- **Time-box the reward** — creates urgency

### K-Factor Formula
```
K = i × c
i = average invites sent per user
c = conversion rate of invites to signups
K > 1 = viral growth | K = 0.5 means every 2 users bring 1 more
```
